# DevBills — Plataforma Completa de Gerenciamento Financeiro

## Visão Geral  
DevBills é meu projeto mais completo até agora, desenvolvido para gestão de contas e controle financeiro pessoal ou empresarial. Foi uma oportunidade incrível para dominar TypeScript e Tailwind CSS, além de construir um backend moderno com Node.js, Prisma, MongoDB e Fastify, seguindo boas práticas de segurança e arquitetura.

## Tecnologias Utilizadas  

### Front-end  

- React com TypeScript para interfaces robustas e seguras  

- Tailwind CSS para estilização rápida, flexível e responsiva  

- Axios para comunicação eficiente com a API  

- Lucide React para ícones modernos e personalizáveis

### Back-end  

- Node.js com Fastify para servidor leve e performático  

- Prisma ORM para modelagem e interação com o MongoDB  

- Autenticação Google via Firebase com tokens JWT  

- Validação de dados com Zod  

- Gerenciamento de variáveis sensíveis com arquivos `.env`

## Funcionalidades  

- Dashboard interativo com gráficos precisos e realistas  

- Controle detalhado de despesas e receitas  

- Criação e gestão de categorias personalizadas  

- Cadastro ilimitado de transações financeiras  

- UI intuitiva, responsiva e otimizada para diversos dispositivos  

- Segurança reforçada com autenticação e validação de dados

## Como Rodar o Projeto  

### Pré-requisitos  

- Node.js instalado  

- Configurar variáveis de ambiente para Firebase, banco de dados e outras chaves
